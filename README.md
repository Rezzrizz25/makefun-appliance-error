A washing machine that did everything right and still gets blamed — so it files an honest error report. One line, no excuses, just the truth of the fault.

> Error E04: I heated the water, spun the drum, and drained it twice. The socks are still wet. At this point, it's a you problem.

## Run it

```sh
node main.ts
```

This writes the entry line to `entry.txt` inside `$MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
